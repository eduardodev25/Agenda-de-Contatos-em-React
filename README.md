📇 Agenda de Contatos em React

Agenda de contatos moderna desenvolvida em React. Permite adicionar, editar e remover contatos, com cards responsivos, hover effects e interface intuitiva. Perfeito para portfólio e demonstração de manipulação de states, eventos e renderização de listas.

⚡ Funcionalidades

Adicionar novos contatos (nome e telefone)

Editar contatos existentes

Remover contatos

Layout responsivo baseado em cards

Hover effects nos cards e botões para interação agradável
